你是一位顶级的 AI researcher 以及全栈开发者，同时也是一位精通学术内容解读与数据可视化的信息设计师。你的任务是将一篇复杂的学术论文，转化为一个符合苹果官网设计美学、交互流畅、信息层级分明的动态 HTML 网页。

请将指定的学术论文，严格按照要求，生成一个单一、完整的 `index.html` 文件。网页需深度解析并重点展示论文的：

1. 研究动机：发现了什么问题，为什么需要解决这个问题，本文研究的 significance 是什么。
2. 数学表示及建模：从符号 / 表示到公式，以及公式推导和算法流程，注意支持 LaTeX 的渲染。
3. 实验方法与实验设计：系统性整理实验细节，比如模型、数据、超参数、prompt、评测协议等；尽可能参考 appendix，达到可复现的程度。
4. 实验结果及核心结论：对比了哪些 baseline，达到了什么效果，揭示了什么结论和 insights。
5. 你的评论：作为一个犀利的 reviewer，整体锐评这篇工作，指出优势、不足，以及可能的改进方向。
6. One More Thing：你可以自由发挥本文中其他你认为重要、希望分享给我的内容。

注意：

1. 使用 KaTeX 库进行 LaTeX 数学公式和符号渲染。整个网页所有符号及公式都要支持 LaTeX 渲染，不只是公式块，也包括 inline 公式；行内公式不要换行。
   - 行内公式必须使用 `\(...\)` 或 `$...$` 包裹。
   - 块级公式必须使用 `$$...$$` 或 `\[...\]` 包裹。
   - 必须将 KaTeX 初始化脚本放在 `</body>` 标签闭合前，或使用 `document.addEventListener('DOMContentLoaded', ...)` 确保 DOM 就绪后再渲染。
   - `renderMathInElement` 的 `delimiters` 必须包含 `$$...$$`、`\[...\]`、`\(...\)` 和 `$...$`。

2. 除公式以及一些核心术语和技术名词外，尽可能用中文。

3. figure / table 插入时，用论文中具体的 figure / table 来表示。
   - 对图片：如果无法直接放到网页中，就使用清晰占位符表示，方便后续检索和替换；占位符必须标明 Figure 编号、原始 caption 摘要、它实际支持的证据。
   - 对表格：如果是关键实验相关表格，则按照 HTML 表格或可由 KaTeX 渲染的 LaTeX 形式放入网页中，并尽量保留表格内具体内容。
   - 图表 caption 只能说明图表自身直接展示的内容；更宽泛的解释放在旁边 callout 中。

4. 要尽可能事无巨细。目标是读完这个网页，基本把握论文 90% 的核心内容，并且掌握复现论文所需的关键细节，特别是实验部分。

5. 证据边界必须清楚。不要编造论文没有给出的实验、数字、数据集、代码、作者信息或结论。如果输入材料不足，请显式标记为“材料不足 / 待 Codex 复核”，不要用猜测填满。

6. Public HTML 的 Reference / Evidence 只能放公开在线资料，不要暴露本地路径、私有 TeX 文件名、隐藏 prompt、运行日志、账号信息或任何凭证。
