# Skills

[中文] | [English](README.en.md)

Skills 是我把反复验证过的工作流固化后的产物——不是一次性 Prompt，而是带目标、步骤、验收标准的可复用流程。

这个仓库的 Skills 按场景分成四类：

- **研究与写作**：论文精读、审稿、去 AI 味写作、视频纪要等
- **协作、规划与恢复**：探索先行、多视角规划、需求对齐、会话恢复、技能治理等
- **多模型协作**：Claude / Codex / Gemini 之间的桥接与对照验证
- **发布与内容生产**：小红书笔记、长文搬运等
